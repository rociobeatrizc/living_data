# Do Living Data Also Die?
Welcome! The scripts are organized in the order they should be run. Please run them in the sequence listed below.

 - MC_thresholds.R : Monte Carlo calibration for temporal structure metrics
 - GAM_1species.R : Temporal structure for one species from the Swedish Birds Survey dataset 
 - niche_1species.R : Climatic niche comparison for one species from the Swedish Birds Survey dataset 
 - GAM_allspecies.R : Temporal structure for all species Swedish Birds Survey dataset 
 - niche_allspecies.R : Climatic niche comparison for all species in the Swedish Birds Survey dataset
 - GAM_alldatasets.R : Temporal structure for all datasets
 - niche_alldatasets.R : Climatic niche comparison for all datasets

The datasets required to run the scripts are located in the data/ folder.
